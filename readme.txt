# 🌿 KeenKeeper

A modern friendship tracking and relationship management web app built with React.  
KeenKeeper helps you stay connected with friends by tracking interactions, setting reminders, and visualizing communication habits.

---

## 📌 Project Description

KeenKeeper is a smart relationship tracker where users can:

- Add and view friends
- Track last contact time
- Log interactions (Call, Text, Video)
- Visualize communication activity with analytics
- Stay consistent with relationship goals

It is designed as a responsive, dashboard-style application with a clean UI and smooth user experience.

---

## 🛠️ Technologies Used

- React.js
- React Router
- Tailwind CSS
- DaisyUI
- Recharts
- React Icons
- LocalStorage (for persistent data)
- React Toastify

---

## 🚀 Key Features

### 1. 👥 Friend Management System
Add and display friends with detailed profiles including status, tags, and contact history.

### 2. ⚡ Interaction Tracking
Log Call, Text, and Video interactions and automatically store them in a timeline.

### 3. 📊 Analytics Dashboard
Visualize interaction data using a dynamic Pie Chart and highlight the most used communication method.
